# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-12-13

### Added

- Initial release of The Flames Game.
- Classic FLAMES game logic with animated results.
- Manual mode for step-by-step calculation.
- "How It Works" tutorial page.
- Global statistics and trends visualization.
- Seasonal themes support.
- PWA support for installation on mobile devices.
- Accessibility features (screen reader support, keyboard navigation).

### Changed

- Updated UI with Tailwind CSS v4 and Framer Motion animations.
- Improved performance with optimized assets and code splitting.
